# Visão geral do BoraMarcar

O BoraMarcar é um SaaS de agendamento e gestão para estabelecimentos de serviços (barbearias, salões, etc.).

## Para o dono do negócio

- Painel admin em `/admin` para serviços, profissionais, agenda, clientes e configurações.
- Página pública de agendamento por link (slug do estabelecimento).
- White-label: cores e logo do tenant na página pública.

## Suporte

- Este assistente responde dúvidas frequentes sobre o produto.
- Para problemas urgentes ou casos específicos de cobrança, use **Falar com humano** (e-mail ou WhatsApp).

## O que ainda não está no produto (roadmap)

- Integração Google Agenda
- WhatsApp Business API automático
- Export Excel/PDF de relatórios
- Pacotes/assinaturas para o cliente final

Se o usuário perguntar sobre esses itens, informe que ainda não estão disponíveis.
